Cantonese Learning Web V7.3

Admin features:
- Create/save lessons WITHOUT uploading video, audio, or PDF. Media files are optional.
- Add conversation phrases and optional phrase audio.
- Create/delete Student accounts.

Run:
1. npm install
2. npm start
3. Open http://localhost:3000

Admin: admin / admin123
Student: student / student123

For lesson save, Title and Main Cantonese are required. Video, Audio, PDF are optional.
